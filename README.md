# AI 學習平台 · 5 堂課程

> 中六 · 10 小時 · 唔需要識寫程式

## 👉 學生入口

**https://kelvin0611.github.io/ai-platform-course/**

用電話開都得。每一堂有齊：**要明白咩 → 步驟 → 可以複製嘅 Prompt**。

## 呢個 repo 有咩

| 檔案 | 做咩 |
|---|---|
| `index.html` | 課程網站（學生睇嘅嘢）|
| `template/index.html` | **起手檔** —— 學生由呢個開始改 |
| `prompts.md` | 全部 Prompt（想印出嚟就用呢個）|

## 點用

1. 學生開課程網站
2. 揀今日嗰堂
3. **先睇「先明白」**（兩三句，唔好跳）
4. 跟住步驟，逐步撳「複製」→ 貼落 Cursor
5. 每一步都睇「你會見到」—— 對唔上就係出咗事

## 五堂一覽

| 堂 | 主題 | 做完之後 |
|---|---|---|
| 1 | 出第一件作品 | 一個虛擬實驗，放上導師平台，有條真 link |
| 2 | 起自己個平台 | 有自己平台名嘅首頁 + 3 個科目 |
| 3 | 撳得入去 + 放自己嘅嘢 | 撳入去見到堂 1 造嗰個實驗 |
| 4 | 加你自己揀嘅功能 | 自選功能用得，原本嘢冇壞 |
| 5 | 出街 | 公開 link + QR code + 3 分鐘 demo |

## 三句口頭禪

> 1. **「你要嘅係咩？用一句話講出嚟，先撳 Enter。」**
> 2. **「跑一次，睇住個畫面。」**
> 3. **「AI 話做好咗，唔等於做好咗。」**

## 維護（導師用）

課程內容全部喺 `index.html` 裡面，用 `<section data-lesson="N">` 分堂。
每步係一個 `<div class="step">`，入面嘅 `<pre class="prompt">` 就係學生複製嘅嘢。

改完直接 push，GitHub Pages 一分鐘內更新。
