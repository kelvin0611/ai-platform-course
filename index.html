AI 學習平台 · 5 堂

唔需要識寫程式 — 只需要識講清楚你想要咩

堂 1 · 出第一件作品

今日目標：做一個虛擬實驗，放上導師嘅平台，見到條真 link。

先明白

Cursor 係一個「用文字叫電腦做嘢」嘅程式。你打得越清楚，佢做得越準。 你今日唔會學寫程式 —— 你會學講清楚你要咩，同埋睇佢有冇做對。
1

開一個新檔

開 Cursor → 新檔 → 存做 index.html（一定要係呢個名）

2

先問，唔好做

複製下面嘅字 → 貼去 Cursor 個 chat 框 → 撳 Enter → 睇佢答咩

我完全冇學過程式。用 3 句話我知：
Cursor 係咩？佢同 ChatGPT 有咩分別？
唔好講功能清單，用一個比喻。

你會見到：AI 用一個比喻解釋。睇完就夠，唔使記。

3

做你嘅實驗

複製 → 貼 → Enter → 等佢寫完 → 撳 ▶ 跑 睇畫面

我想要一個網頁，係一個虛擬實驗，主題係：<填你嘅主題>。

要有：
1. 一個標題，寫清楚做咩實驗
2. 一個可以拉嘅滑桿，改變一個數值
3. 一個即時更新嘅結果（數字或者圖）
4. 一句話解釋「點解會有呢個結果」

設計：大字、顏色清楚、電話睇都要清楚。
唔要：唔要登入、唔要後端、唔要廣告。
只用一個 index.html 檔。

做完之後，用 5 句解釋你加咗咩。

你會見到：一個有滑桿嘅網頁。拉吓佢，數字會變。

冇反應？你係唔係冇撳 Enter？或者貼咗喺個檔入面而唔係 chat 框？
4

改一個位

睇下邊度唔靚 → 複製下面嘅字，填你想改嘅嘢

而家 <邊個位> 唔好，我希望 <變成點>。
只改呢部分，其他唔好郁。改完話我知你改咗邊一行。

你會見到：淨係嗰個位變咗，其他嘢冇郁。

大忌：一次改幾個位。改一個 → 跑一次 → 再改下一個。
5

放上平台

開 導師嘅平台 → 填姓名、電郵、標題、摘要 → 揀你嘅 index.html → 撳「更新預覽」→ 撳「送出審核」

你會見到：送完之後導師批咗，你就有一條真 link，send 得畀人。

送完見唔到？正常。所有平台都係咁：你交嘢 → 有人睇 → 批咗才出街。

堂 2 · 起自己個平台

今日目標：一個有你自己平台名嘅首頁，3 個科目，撳得。

先明白

一個平台有幾層，好似一個書架：最上層係首頁，下面每格係一個科目。 你唔會將所有書掉喺地下 —— 分開先搵得到。
1

計劃你個平台

先喺紙上面寫低：平台叫咩名？畀邊個用？放 3 類咩內容？

我個平台叫「<你嘅平台名>」，係畀中學生用嘅。
我打算放呢幾類內容：筆記、虛擬實驗、<自訂>。

先唔好寫 code。用 3 句話我知首頁應該展示咩先最有用。

你會見到：AI 建議你首頁點排。你可以唔同意。

2

做首頁

複製 → 貼 → 等 → 撳 ▶ 睇

我想要一個網頁，係我嘅學習平台首頁。

平台名：<填>
要有：
1. 大大嘅平台名喺頂
2. 一句話介紹（下面細細行）
3. 下面 3 個「科目卡」，每個有科名同一個 emoji
4. 每個卡撳落去要有反應（暫時彈一句「即將推出」都得）

設計：乾淨、大字、卡片圓角、電話睇都清楚。
唔要：唔要登入、唔要後端、唔要廣告。
只用一個 index.html 檔。

做完用 5 句解釋你加咗咩。

你會見到：3 個科目卡。撳落去有反應。

成日漏：唔記得講「撳落去要有反應」→ AI 會出 3 個死嘅字。補一句就得。
3

執靚

揀一個你最唔滿意嘅位，用同一句「只改呢部分」

而家 <邊個位> 唔好，我希望 <變成點>。
只改呢部分，其他唔好郁。

堂 3 · 撳得入去 ＋ 放你自己嘅嘢

今日目標：撳科目卡 → 入到一版，見到你堂 1 造嗰個實驗。

先明白

「撳一個掣，去另一版」叫做導覽。 做一個檔定分開幾個檔都得 —— 好似一間大房同一間屋嘅分別。今日我哋全部放同一個檔，因為交得方便。
1

問有咩做法

複製 → 貼 → 睇佢答（唔使明晒，知有兩條路就夠）

我想要「撳一個掣之後入到另一版」。

先唔好寫 code。用 3 句話我知有邊兩種做法，
各自好處同壞處。用「一間房」同「一間屋」嘅比喻。
2

做科目頁

複製 → 貼 → 撳 ▶ → 試吓撳入去、再撳返出嚟

我而家想：撳「<科目名>」卡之後，出一個科目頁。

科目頁要有：
1. 科目名喺頂，有個「← 返回」掣
2. 一個列表，列出 2-3 項（例：<你嘅筆記名>、<你嘅實驗名>）
3. 每一項撳落去有反應

只改呢部分，其他唔好郁。做完解釋你加咗咩。

你會見到：撳入去有新版，撳「← 返回」返得返出嚟。

3

放你自己嘅實驗入去

複製 → 貼 → 撳 ▶ → 睇下你自己堂 1 個實驗出唔出到

我有一個之前做好嘅 HTML，係一個虛擬實驗。
我想喺科目頁撳某一項，下面就直接顯示嗰個實驗。

用 iframe 做。如果技術上做唔到，話我知，
同埋建議我另一個做法。

只改呢部分，其他唔好郁。

你會見到：撳一項，下面出現你堂 1 造嗰個實驗。

唔緊要：如果 AI 話做唔到，好正常。佢會畀你另一個做法 —— 就用佢嗰個。

堂 4 · 加你自己揀嘅功能

今日目標：加一個你自己揀嘅功能，而且用得，而且原本嘅嘢冇壞。

先明白

到而家為止你都係照住做。今日開始你話事。 一個好嘅平台，係由「用家覺得煩」嘅地方改出嚟 —— 而你自己就係用家。
1

叫 AI 畀建議，你揀一個

複製 → 貼 → 睇 5 個建議 → 揀一個（唔好揀「難」）

我個學習平台而家有：首頁、3 個科目、一個科目頁。

畀我 5 個「中學生會覺得有用」嘅功能建議。
每個寫：功能名、解決咩問題、難度（易／中／難）。
只做得到「一個 HTML 檔內」嘅嘢。

你會見到：5 個建議，每個有難度。揀一個「易」嘅。

2

做佢

複製 → 貼 → 撳 ▶ → 試到用得為止

加一個 <你揀嘅功能>。

<具體描述你想要咩>

只加呢樣，其他唔好郁。
做完話我知你改咗邊幾行。
加之前：先跑一次原有嘅嘢，確認原本冇壞。唔係壞咗你都唔知係新定舊。
3

出事用呢句 ⭐

壞咗、或者怪怪地？唔好即刻叫佢改 —— 叫佢先諗

我撳咗 ，出咗 ，但我想要 。

先唔好改 code。先用 3 句講你估係咩原因，同埋你點知。
我確認之後你才改。

點解要咁：咁你就會知佢係唔係亂估。呢句係全個課程最重要嘅一句。

堂 5 · 出街

今日目標：一條公開 link ＋ QR code ＋ 3 分鐘 demo。

先明白

之前個檔喺你自己部電腦，只有你睇到。 放上網之後，全世界都開得到 —— 好似一張紙同一張貼咗出街嘅海報。
1

交檔畀導師

你嘅 index.html 交畀導師（AirDrop／Google Drive／USB 都得）→ 導師幫你放上網 → 派你一條 link 同 QR code

你會見到：用電話開條 link，同你電腦見到一樣。

2

執好你嘅 3 分鐘稿

一定要答到呢 3 條：

① 我個平台係畀邊個用？佢會用嚟做咩？
② 我加咗邊個功能係我自己揀嘅？點解揀佢？
③ 我撞到咩問題？我點樣叫 AI 幫我搞掂？

第 ③ 條最重要。唔係講「成功」，係講過程。撞板嘅嘢講出嚟更值錢。
3

Demo

每組 3 分鐘。之後全班投票：🏆 最想用 ｜ 🎨 最靚 ｜ 🧠 最識問 AI

🆘 救命卡

卡住嘅時候嚟呢度。唔好重做，唔好亂撳。
?

睇唔明 AI 寫咩

我睇唔明你頭先做咗咩。

用一個生活比喻講一次；
再列出你改咗嘅 3 個最重要嘅位，每個一句。
唔好重寫 code。
?

改完之後壞咗

你頭先改完之後壞咗。
還原返上一個版本，然後話我知你上次改咗咩。
?

佢改咗你冇叫佢改嘅嘢

你改咗我冇叫你改嘅嘢。
只改我講嗰個位，其他還原。
?

亂晒，想重新開始

而家好亂。

用 5 句話我知而家個檔案有咩、邊度有問題。
唔好改任何嘢。
?

進度落後

我進度落後。
幫我揀出最重要嘅一個功能，其他全部暫時唔要。
只留呢個。
?

五條鐵律（記住呢五句就夠）

1. 一次只改一個位 —— 改完即刻跑一次
2. 唔明就問「點解」—— 唔好照 copy
3. 唔明就講「我睇唔明」—— 佢會翻譯成人話
4. 壞咗唔好重做 —— 講返「我撳咗 X 出咗 Y 我想要 Z」
5. 交嘢之前，自己先用一次 —— 冇試過唔算完成
