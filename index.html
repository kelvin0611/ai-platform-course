AI 學習平台 · 5 堂

唔需要識寫程式 — 只需要識講清楚你想要咩

🔥 熱身 · 上第一堂之前

今日目標：喺自己部電腦睇到一個網頁 —— 就係咁簡單。

先明白

寫咗一個檔，唔撳「跑」，係唔會知啱唔啱嘅。 好似煮完嘢一定要試味 —— 唔試，你點知落少咗鹽？
1

開一個資料夾

喺桌面開一個資料夾，改名做 my-platform（唔好用中文名、唔好有空格）。 之後所有嘢都放喺呢個資料夾入面。

為咩要咁：檔名同路徑乾淨，之後出事機會少好多。

大忌：檔名用中文、空格、或者放喺「下載」度。
2

用 Cursor 開個資料夾

Cursor → File → Open Folder → 揀啱啱嗰個 my-platform

你會見到：左邊出現你個資料夾名，入面係空嘅。之後所有新檔都會喺呢度。

3

睇到自己個網頁（三個方法，由易到難）

A · 最簡單：雙擊 index.html → 用 Chrome 開
B · 喺 Cursor 度開：右擊個檔 → Open with… 或者用 Cursor 內建預覽
C · 真 server：python -m http.server 8000 → Chrome 打 http://localhost:8000 

我係用 Windows，啱啱裝好 Cursor。
我寫好咗一個 index.html，想睇下佢係點樣。

用最簡單嘅方法，一步一步教我點樣喺 Chrome 睇到佢。
每一步都寫：撳咩、打咩、會見到咩。
如果唔需要開 server 就咁開得，話我知。

你會見到：Chrome 開到你寫嘅頁面。

唔好一開始就搞 server。開得到先講 —— A 唔得，才試 B，再唔得才 C。
4

要真 server 嘅時候（Windows）

當你有幾個檔（index.html ＋ lab.html），或者 A／B 都出問題，就用呢條

我想喺 Windows 開一個本機預覽伺服器（local server），
咁我就可以用 http://localhost:8000 睇我自己嘅網頁。

一步一步教我：
1. 要打咩指令、喺 Cursor 邊個位打
2. 打完會見到咩
3. 之後點樣喺 Chrome 開
4. 用完點樣閂

我部電腦未必裝咗 Python。如果冇，話我知最簡單嘅替代方法。

你會見到：一步步嘅指示。跟住做，Chrome 打 localhost 就見到你自己個網頁。

開唔到？去 Prompt 表格撳右上角「🆘 有問題？」→ 有條專門講 Windows server。
5

明白發生咩事

唔明就問 —— 唔好死記步驟

用 3 句話我知：
「開 local server」同「直接雙擊個 HTML 檔」有咩分別？
用一個生活比喻。唔好講技術名詞。

你會見到：一個比喻，你會明點解有時要 server、有時唔需要。

💾 儲存 · 每堂都要做

今日目標：你嘅 code 全部放喺自己嘅 GitHub。下一堂坐邊部電腦都攞得返。

先明白

你寫嘅嘢而家只喺呢一部電腦。好似你喺一張紙寫低嘢，但係紙冇帶走。 放上 GitHub = 影印一份鎖喺櫃，你去到邊都攞得返。
1

第一次：裝 Git ＋ 開 GitHub

兩樣都係一次過嘅事。叫 AI 一步步教你。

我係用 Windows，未裝過 Git。

一步一步教我點裝：
1. 去邊度下載（要撳咩）
2. 裝嘅時候有咩要改（如果全部預設都得，話我知）
3. 裝完之後，點確認真係裝好

用中學生明嘅講法，唔好假設我識任何嘢。

裝完之後，開 GitHub 帳號同一個 repo：

我未有 GitHub 帳號。

一步一步教我：
1. 點註冊（用邊個 email 好）
2. 點開一個新 repo
3. 個 repo 叫咩名好（我個 project 係一個學習平台）
4. 揀 public 定 private？分別係咩
5. 開完之後我會見到咩

用中學生明嘅講法。

你會見到：Git 裝好、你有個 GitHub 帳號、有個空嘅 repo。

呢步只做一次。之後每堂都唔使再做。
2

第一次：叫 AI 幫你上傳

複製 → 填你個資料夾路徑同 repo 網址 → 佢會幫你跑指令

我嘅 code 喺呢個資料夾：<資料夾路徑>
我啱啱開咗一個 GitHub repo：

請你幫我：
1. 喺呢個資料夾建立 git
2. 連接去嗰個 repo
3. 將所有檔上傳上去

指令你幫我跑（或者一步一步話我知要打咩）。
跑完話我知成功定失敗，同埋我點自己確認。

跟住一定要自己驗證：

我頭先叫你幫我上傳咗。

教我點自己確認真係成功（唔係只係你話成功）：
1. 我可以去邊度睇
2. 應該見到咩
3. 如果見到舊嘅版本，代表咩

唔好改任何嘢。

你會見到：去 GitHub 網站撳你個 repo，見到你啲檔。

AI 話成功 ≠ 成功。自己開一次 GitHub 睇，見到才算。
3

每堂開始：攞返上次嘅 code

換咗電腦就一定要做。複製 → 填 repo 網址 → 佢幫你攞返所有檔

我而家喺一部新嘅電腦（或者重裝過）。
我上次嘅 code 放咗喺 GitHub：

一步一步教我點樣攞返所有檔落嚟：
1. 要打咩指令、喺 Cursor 邊個位打
2. 會存喺邊個資料夾
3. 攞完之後點樣喺 Cursor 開嚟睇

你幫我跑都得。跑完話我知我應該見到咩。

（如果係同一部電腦，唔使重新 clone，叫 AI 做 git pull 就得。）

你會見到：上次所有檔返晒嚟，開喺 Cursor 見到。

4

每堂落堂：儲存 ＋ 上傳

落堂前最後一件事 —— 唔做就等於今日白做。

我要落堂喇，要將今日做嘅嘢全部存上 GitHub。

請你幫我：
1. 先列出今日改咗邊幾個檔（我想睇下先）
2. 幫我寫一句 commit message（英文，一句為限）
3. 上傳上去

跑完話我知成功定失敗，同埋我點自己確認。

你會見到：佢列出你改過嘅檔，然後上傳成功。

為咩要「列畀我睇」：你會知自己有冇唔小心改咗啲唔應該改嘅嘢。
5

明白發生咩事

唔好死背指令 —— 明咗就唔會驚

用 3 句話我知：
「儲存」同「上傳」有咩分別？commit 同 push 又係咩？

用一個比喻（提示：好似寫日記同寄出去）。
唔好講指令。

你會見到：一個比喻。三個名：add 揀檔、commit 打記錄、push 寄出去。

出問題？去 Prompt 表格「💾 儲存」分頁撳右上角「🆘 有問題？」。

堂 1 · 出第一件作品

今日目標：做一個虛擬實驗，放上導師嘅平台，見到條真 link。

先明白

Cursor 係一個「用文字叫電腦做嘢」嘅程式。你打得越清楚，佢做得越準。 你今日唔會學寫程式 —— 你會學講清楚你要咩，同埋睇佢有冇做對。
1

開一個新檔

開 Cursor → 新檔 → 存做 index.html（一定要係呢個名）

2

先問，唔好做

複製下面嘅字 → 貼去 Cursor 個 chat 框 → 撳 Enter → 睇佢答咩

我完全冇學過程式。用 3 句話我知：
Cursor 係咩？佢同 ChatGPT 有咩分別？
唔好講功能清單，用一個比喻。

你會見到：AI 用一個比喻解釋。睇完就夠，唔使記。

3

做你嘅實驗

複製 → 貼 → Enter → 等佢寫完 → 撳 ▶ 跑 睇畫面

我想要一個網頁，係一個虛擬實驗，主題係：<填你嘅主題>。

要有：
1. 一個標題，寫清楚做咩實驗
2. 一個可以拉嘅滑桿，改變一個數值
3. 一個即時更新嘅結果（數字或者圖）
4. 一句話解釋「點解會有呢個結果」

設計：大字、顏色清楚、電話睇都要清楚。
唔要：唔要登入、唔要後端、唔要廣告。
只用一個 index.html 檔。

做完之後，用 5 句解釋你加咗咩。

你會見到：一個有滑桿嘅網頁。拉吓佢，數字會變。

冇反應？你係唔係冇撳 Enter？或者貼咗喺個檔入面而唔係 chat 框？
4

改一個位

睇下邊度唔靚 → 複製下面嘅字，填你想改嘅嘢

而家 <邊個位> 唔好，我希望 <變成點>。
只改呢部分，其他唔好郁。改完話我知你改咗邊一行。

你會見到：淨係嗰個位變咗，其他嘢冇郁。

大忌：一次改幾個位。改一個 → 跑一次 → 再改下一個。
5

放上平台

開 導師嘅平台 → 填姓名、電郵、標題、摘要 → 揀你嘅 index.html → 撳「更新預覽」→ 撳「送出審核」

你會見到：送完之後導師批咗，你就有一條真 link，send 得畀人。

送完見唔到？正常。所有平台都係咁：你交嘢 → 有人睇 → 批咗才出街。

堂 2 · 你個平台出世

今日目標：骨架已經幫你做好 —— 首頁、側欄、科目頁、內容頁，仲有新聞區、測驗區、小測區。你要做嘅係令佢變成你嘅：改【資料區】，再加一個功能。

先明白

個檔分咗兩邊：【資料區】係你嘅內容，【引擎區】係令佢行得嘅嘢。 好似一本書：你可以換晒裡面嘅字，書本身唔會散。
所以改資料，係唔會搞壞個平台嘅。
1

攞起手檔，跑一次

導師會派你兩個檔：index.html 同 lab.html → 兩個放埋同一個資料夾 → 用 Cursor 打開嗰個資料夾 → 撳 ▶ 跑一次

漏咗？可以喺 呢度 再攞（右鍵 → 另存新檔）

你會見到：頂部橫梁 ＋ 左邊側欄 ＋ 3 個科目卡，撳得入去、返得返出嚟。你唔需要由零開始。

2

先問，唔好做

複製 → 貼 → 睇佢答。明白咗才做下一步。

我有一個 index.html，係一個學習平台嘅骨架。
入面分咗【資料區】同【引擎區】。

用 3 句話我知：點解要分開？
用一個生活比喻。唔好講 code。

你會見到：一個比喻，講「內容」同「機制」嘅分別。

3

改平台名

複製 → 貼 → 跑一次 → 睇下邊幾個地方變咗

喺【資料區】入面：
個平台由「我嘅學習平台」改做「<你嘅平台名>」，
tagline 改做「<一句話介紹>」。

只改【資料區】，唔好郁【引擎區】。

你會見到：頂部橫梁、側欄、瀏覽器 tab 嘅名一齊變。

留意呢點：你只改一個位，三個地方跟住變 —— 因為佢哋讀同一份資料。
4

換你嘅科目

複製 → 填你自己嘅 3 個科目 → 跑一次

喺【資料區】入面，將 3 個科目改成我自己嘅：

1. <科目一> emoji 用 ，描述：<一句>
2. <科目二> emoji 用 ，描述：<一句>
3. <科目三> emoji 用 ，描述：<一句>

只改【資料區】。

你會見到：首頁同側欄都變咗你嘅科目。

5

換配色

叫佢換走主色 —— 令你個平台唔似人哋嗰個

我想換走主色，變成 <你想要嘅色>。

只改最上面 :root 入面嘅色值，其他一律唔好郁。
換完話我知你改咗邊幾行。如果咁樣會變醜，警告我。

你會見到：成個平台嘅色一齊變。

呢步學到：改一個值，全部跟住變 —— 呢個叫「設計變數」。
6

今日挑戰：加「最近更新」

呢次你自己寫描述。複製 → 填中間嗰句 → 做到用得為止

我想喺首頁加一個「最近更新」區，
用細細張卡列出最新 3 項內容，撳得入去。

只加呢樣，其他唔好郁。
做完話我知你改咗邊幾行。

你會見到：首頁多咗一區。

佢可能會問你：「最新」點定義？ —— 你就係要答嘅人。試下自己諗一個講法。

堂 3 · 放你自己嘅內容入去

今日目標：堂 1 造嘅虛擬實驗、自己寫嘅筆記 —— 全部放入你個平台。

先明白

【資料區】入面，每一項內容都有一個 type：note（筆記）同 lab（虛擬實驗）。 好似一個櫃有幾種格 —— 你話佢係邊種，佢就知點展示。
1

先問，唔好做

複製 → 貼 → 睇佢答。明白咗才做下一步。

【資料區】入面每個內容都有 type，有 "note" 同 "lab"。

用 3 句話我知：點解要有 type？
如果我想加一種新 type，大概要改咩？

你會見到：AI 講「type 決定點展示」。呢個概念之後你自己都用得着。

2

加一則筆記

複製 → 填你自己嘅標題同內容 → 跑一次 → 去側欄搵下佢

喺「<科目名>」入面加一則筆記：

標題：<你嘅標題>
內容：<你寫嘅一兩句>

只改【資料區】。加完話我知我喺側欄邊度搵到佢。

你會見到：側欄多咗一項，撳得入去見到你寫嘅嘢。

3

再加一則

同樣嘅事做第二次 —— 呢次試下唔問 AI 點做

再喺同一科加一則筆記：
標題：<你嘅標題>
內容：<你寫嘅內容>

只改【資料區】。
愈做愈快：第二次你已經大概知喺邊度加。呢個就係「上手」。
4

放入你嘅虛擬實驗

將堂 1 造嗰個檔改名做 lab.html，同 index.html 放同一個資料夾 → 跑一次

我堂 1 造咗一個虛擬實驗，我想放入「<科目名>」。

我已經將佢改名做 lab.html，同 index.html 放喺同一個資料夾。
【資料區】入面已經有一項 type:"lab"，src 係 "lab.html"。

確認佢真係駁得通。
如果 iframe 出唔到，話我知係咩原因（用 3 句）。

你會見到：撳嗰項，下面直接出現你自己堂 1 造嗰個實驗。

睇唔到？確認兩個檔真係同一個資料夾，而且個實驗檔真係叫 lab.html（大細寫要一樣）。
5

今日挑戰：加「同科其他內容」

自己寫描述。複製 → 填中間 → 做到用得為止

內容頁最底加一個「同科其他內容」區，
列出同一科其他項，撳得入去。
目前睇緊嗰項唔好列出嚟。

只加呢樣，其他唔好郁。

你會見到：睇完一則筆記，下面有得跳去同科其他嘢。

堂 4 · 填滿三個新區

今日目標：骨架已經有新聞區、測驗區、小測區。你要做嘅係填內容，再改一個功能。

先明白

測驗題目係咁樣存嘅：{ q:"問題", options:["A","B","C"], answer:0 } —— answer 由 0 開始數。第一個選項係 0，唔係 1。 好似樓層：地面係 0 樓。
1

先問，唔好做

複製 → 貼 → 睇佢答。呢條幫你避開最常撞嘅錯。

我個平台有一個測驗區，題目係咁樣存嘅：

{ q:"問題", options:["A","B","C"], answer:0, explain:"解釋" }

用 3 句話我知：answer:0 係咩意思？
如果我加一題，有咩位容易打錯？

你會見到：AI 提醒你「由 0 開始數」同其他易錯位。

2

加一則新聞

複製 → 填你嘅內容 → 跑一次 → 撳入新聞區睇下

喺【資料區】嘅 news 入面加一則新聞：

日期：<今日日期>
標題：<你嘅標題>
內容：<兩三句>

只改【資料區】。加完話我知我喺邊度見到佢。

你會見到：新聞區多咗一則，撳得入去睇詳細。

3

加一份測驗

複製 → 一次過填齊 3 題 → 跑一次 → 試下做完整份，睇下分數對唔對

喺【資料區】嘅 quizzes 入面加一份新測驗：

科目：<科目名>
標題：<你嘅測驗名>
題目：
1. <問題> 選項： /  / ，正確答案係 <第幾個>，解釋：<一句>
2. <問題> 選項： /  / ，正確答案係 <第幾個>，解釋：<一句>
3. <問題> 選項： /  / ，正確答案係 <第幾個>，解釋：<一句>

只改【資料區】。做完話我知每一題嘅 answer 你填咗幾多。

你會見到：測驗區多咗一份。做完成份撳交卷，會計分同逐題話你知對錯。

一定要自己做完一次。如果分數計錯，就係 answer 填錯 —— 呢個就係驗收。
4

加幾題小測

複製 → 填 3 題 → 跑一次 → 玩一次睇即時對錯

喺【資料區】嘅 quick 入面加 3 題快問快答：

1. <問題> 選項： /  / ，正確答案 <第幾個>，解釋：<一句>
2. <問題> 選項： /  / ，正確答案 <第幾個>，解釋：<一句>
3. <問題> 選項： /  / ，正確答案 <第幾個>，解釋：<一句>

只改【資料區】。

你會見到：小測區多咗 3 題，撳一個選項即時知對錯，仲有解釋。

5

改一個功能（自己話事）

呢次冇 prompt 畀你抄 —— 你自己寫。填中間嗰句要夠具體。

我想改 <邊個區／邊個位>：<由點樣> 變成 <點樣>。

<用你自己嘅話描述你想要咩>
