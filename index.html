AI 學習平台 · 5 堂

唔需要識寫程式 — 只需要識講清楚你想要咩

堂 1 · 出第一件作品

今日目標：做一個虛擬實驗，放上導師嘅平台，見到條真 link。

先明白

Cursor 係一個「用文字叫電腦做嘢」嘅程式。你打得越清楚，佢做得越準。 你今日唔會學寫程式 —— 你會學講清楚你要咩，同埋睇佢有冇做對。
1

開一個新檔

開 Cursor → 新檔 → 存做 index.html（一定要係呢個名）

2

先問，唔好做

複製下面嘅字 → 貼去 Cursor 個 chat 框 → 撳 Enter → 睇佢答咩

我完全冇學過程式。用 3 句話我知：
Cursor 係咩？佢同 ChatGPT 有咩分別？
唔好講功能清單，用一個比喻。

你會見到：AI 用一個比喻解釋。睇完就夠，唔使記。

3

做你嘅實驗

複製 → 貼 → Enter → 等佢寫完 → 撳 ▶ 跑 睇畫面

我想要一個網頁，係一個虛擬實驗，主題係：<填你嘅主題>。

要有：
1. 一個標題，寫清楚做咩實驗
2. 一個可以拉嘅滑桿，改變一個數值
3. 一個即時更新嘅結果（數字或者圖）
4. 一句話解釋「點解會有呢個結果」

設計：大字、顏色清楚、電話睇都要清楚。
唔要：唔要登入、唔要後端、唔要廣告。
只用一個 index.html 檔。

做完之後，用 5 句解釋你加咗咩。

你會見到：一個有滑桿嘅網頁。拉吓佢，數字會變。

冇反應？你係唔係冇撳 Enter？或者貼咗喺個檔入面而唔係 chat 框？
4

改一個位

睇下邊度唔靚 → 複製下面嘅字，填你想改嘅嘢

而家 <邊個位> 唔好，我希望 <變成點>。
只改呢部分，其他唔好郁。改完話我知你改咗邊一行。

你會見到：淨係嗰個位變咗，其他嘢冇郁。

大忌：一次改幾個位。改一個 → 跑一次 → 再改下一個。
5

放上平台

開 導師嘅平台 → 填姓名、電郵、標題、摘要 → 揀你嘅 index.html → 撳「更新預覽」→ 撳「送出審核」

你會見到：送完之後導師批咗，你就有一條真 link，send 得畀人。

送完見唔到？正常。所有平台都係咁：你交嘢 → 有人睇 → 批咗才出街。

堂 2 · 你個平台出世

今日目標：骨架已經幫你做好（首頁、側欄、科目頁、內容頁）。你要做嘅係令佢變成你嘅 —— 改【資料區】，再加一個新功能。

先明白

個檔分咗兩邊：【資料區】係你嘅內容，【引擎區】係令佢行得嘅嘢。 好似一本書：你可以換晒裡面嘅字，書本身唔會散。
所以改資料，係唔會搞壞個平台嘅。
1

攞起手檔，跑一次

導師會派你兩個檔：index.html 同 lab.html → 兩個放埋同一個資料夾 → 用 Cursor 打開嗰個資料夾 → 撳 ▶ 跑一次

漏咗？可以喺 呢度 再攞（右鍵 → 另存新檔）

你會見到：頂部橫梁 ＋ 左邊側欄 ＋ 3 個科目卡，撳得入去、返得返出嚟。你唔需要由零開始。

2

先問，唔好做

複製 → 貼 → 睇佢答。明白咗才做下一步。

我有一個 index.html，係一個學習平台嘅骨架。
入面分咗【資料區】同【引擎區】。

用 3 句話我知：點解要分開？
用一個生活比喻。唔好講 code。

你會見到：一個比喻，講「內容」同「機制」嘅分別。

3

改平台名

複製 → 貼 → 跑一次 → 睇下邊幾個地方變咗

喺【資料區】入面：
個平台由「我嘅學習平台」改做「<你嘅平台名>」，
tagline 改做「<一句話介紹>」。

只改【資料區】，唔好郁【引擎區】。

你會見到：頂部橫梁、側欄、瀏覽器 tab 嘅名一齊變。

留意呢點：你只改一個位，三個地方跟住變 —— 因為佢哋讀同一份資料。
4

換你嘅科目

複製 → 填你自己嘅 3 個科目 → 跑一次

喺【資料區】入面，將 3 個科目改成我自己嘅：

1. <科目一> emoji 用 ，描述：<一句>
2. <科目二> emoji 用 ，描述：<一句>
3. <科目三> emoji 用 ，描述：<一句>

只改【資料區】。

你會見到：首頁同側欄都變咗你嘅科目。

5

換配色

叫佢換走主色 —— 令你個平台唔似人哋嗰個

我想換走主色，變成 <你想要嘅色>。

只改最上面 :root 入面嘅色值，其他一律唔好郁。
換完話我知你改咗邊幾行。如果咁樣會變醜，警告我。

你會見到：成個平台嘅色一齊變。

呢步學到：改一個值，全部跟住變 —— 呢個叫「設計變數」。
6

今日挑戰：加「最近更新」

呢次你自己寫描述。複製 → 填中間嗰句 → 做到用得為止

我想喺首頁加一個「最近更新」區，
用細細張卡列出最新 3 項內容，撳得入去。

只加呢樣，其他唔好郁。
做完話我知你改咗邊幾行。

你會見到：首頁多咗一區。

佢可能會問你：「最新」點定義？ —— 你就係要答嘅人。試下自己諗一個講法。

堂 3 · 放你自己嘅內容入去

今日目標：堂 1 造嘅虛擬實驗、自己寫嘅筆記 —— 全部放入你個平台。

先明白

【資料區】入面，每一項內容都有一個 type：note（筆記）同 lab（虛擬實驗）。 好似一個櫃有幾種格 —— 你話佢係邊種，佢就知點展示。
1

先問，唔好做

複製 → 貼 → 睇佢答。明白咗才做下一步。

【資料區】入面每個內容都有 type，有 "note" 同 "lab"。

用 3 句話我知：點解要有 type？
如果我想加一種新 type，大概要改咩？

你會見到：AI 講「type 決定點展示」。呢個概念之後你自己都用得着。

2

加一則筆記

複製 → 填你自己嘅標題同內容 → 跑一次 → 去側欄搵下佢

喺「<科目名>」入面加一則筆記：

標題：<你嘅標題>
內容：<你寫嘅一兩句>

只改【資料區】。加完話我知我喺側欄邊度搵到佢。

你會見到：側欄多咗一項，撳得入去見到你寫嘅嘢。

3

再加一則

同樣嘅事做第二次 —— 呢次試下唔問 AI 點做

再喺同一科加一則筆記：
標題：<你嘅標題>
內容：<你寫嘅內容>

只改【資料區】。
愈做愈快：第二次你已經大概知喺邊度加。呢個就係「上手」。
4

放入你嘅虛擬實驗

將堂 1 造嗰個檔改名做 lab.html，同 index.html 放同一個資料夾 → 跑一次

我堂 1 造咗一個虛擬實驗，我想放入「<科目名>」。

我已經將佢改名做 lab.html，同 index.html 放喺同一個資料夾。
【資料區】入面已經有一項 type:"lab"，src 係 "lab.html"。

確認佢真係駁得通。
如果 iframe 出唔到，話我知係咩原因（用 3 句）。

你會見到：撳嗰項，下面直接出現你自己堂 1 造嗰個實驗。

睇唔到？確認兩個檔真係同一個資料夾，而且個實驗檔真係叫 lab.html（大細寫要一樣）。
5

今日挑戰：加「同科其他內容」

自己寫描述。複製 → 填中間 → 做到用得為止

內容頁最底加一個「同科其他內容」區，
列出同一科其他項，撳得入去。
目前睇緊嗰項唔好列出嚟。

只加呢樣，其他唔好郁。

你會見到：睇完一則筆記，下面有得跳去同科其他嘢。

堂 4 · 加你自己揀嘅功能

今日目標：加一個你自己揀嘅功能，而且用得，而且原本嘅嘢冇壞。

先明白

到而家為止你都係照住做。今日開始你話事。 一個好嘅平台，係由「用家覺得煩」嘅地方改出嚟 —— 而你自己就係用家。
1

叫 AI 畀建議，你揀一個

複製 → 貼 → 睇 5 個建議 → 揀一個（唔好揀「難」）

我個學習平台而家有：首頁、3 個科目、一個科目頁。

畀我 5 個「中學生會覺得有用」嘅功能建議。
每個寫：功能名、解決咩問題、難度（易／中／難）。
只做得到「一個 HTML 檔內」嘅嘢。

你會見到：5 個建議，每個有難度。揀一個「易」嘅。

2

做佢

複製 → 貼 → 撳 ▶ → 試到用得為止

加一個 <你揀嘅功能>。

<具體描述你想要咩>

只加呢樣，其他唔好郁。
做完話我知你改咗邊幾行。
加之前：先跑一次原有嘅嘢，確認原本冇壞。唔係壞咗你都唔知係新定舊。
3

出事用呢句 ⭐

壞咗、或者怪怪地？唔好即刻叫佢改 —— 叫佢先諗

我撳咗 ，出咗 ，但我想要 。

先唔好改 code。先用 3 句講你估係咩原因，同埋你點知。
我確認之後你才改。

點解要咁：咁你就會知佢係唔係亂估。呢句係全個課程最重要嘅一句。

堂 5 · 出街

今日目標：一條公開 link ＋ QR code ＋ 3 分鐘 demo。

先明白

之前個檔喺你自己部電腦，只有你睇到。 放上網之後，全世界都開得到 —— 好似一張紙同一張貼咗出街嘅海報。
1

交檔畀導師

你嘅 index.html 同 lab.html（兩個都要交）畀導師（AirDrop／Google Drive／USB 都得）→ 導師幫你放上網 → 派你一條 link 同 QR code

你會見到：用電話開條 link，同你電腦見到一樣。

2

執好你嘅 3 分鐘稿

一定要答到呢 3 條：

① 我個平台係畀邊個用？佢會用嚟做咩？
② 我加咗邊個功能係我自己揀嘅？點解揀佢？
③ 我撞到咩問題？我點樣叫 AI 幫我搞掂？

第 ③ 條最重要。唔係講「成功」，係講過程。撞板嘅嘢講出嚟更值錢。
3

Demo

每組 3 分鐘。之後全班投票：🏆 最想用 ｜ 🎨 最靚 ｜ 🧠 最識問 AI

🆘 救命卡

卡住嘅時候嚟呢度。唔好重做，唔好亂撳。
?

睇唔明 AI 寫咩

我睇唔明你頭先做咗咩。

用一個生活比喻講一次；
再列出你改咗嘅 3 個最重要嘅位，每個一句。
唔好重寫 code。
?

改完之後壞咗

你頭先改完之後壞咗。
還原返上一個版本，然後話我知你上次改咗咩。
?

佢改咗你冇叫佢改嘅嘢

你改咗我冇叫你改嘅嘢。
只改我講嗰個位，其他還原。
?

亂晒，想重新開始

而家好亂。

用 5 句話我知而家個檔案有咩、邊度有問題。
唔好改任何嘢。
?

進度落後

我進度落後。
幫我揀出最重要嘅一個功能，其他全部暫時唔要。
只留呢個。
?

五條鐵律（記住呢五句就夠）

1. 一次只改一個位 —— 改完即刻跑一次
2. 唔明就問「點解」—— 唔好照 copy
3. 唔明就講「我睇唔明」—— 佢會翻譯成人話
4. 壞咗唔好重做 —— 講返「我撳咗 X 出咗 Y 我想要 Z」
5. 交嘢之前，自己先用一次 —— 冇試過唔算完成
